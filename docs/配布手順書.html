税額ポケット 使い方

関与先で税額を出すための計算ツールです。スマートフォンで使います。

1これは何か

スマートフォンのブラウザで開き、ホーム画面に追加して使います。

https://sakurataxsys.github.io/tax-pocket/

いま入っているもの

  • 退職金
  • 減価償却費
  • 印紙税
  • 登録免許税
  • 延滞税・利子税
  • 法人税の早見表
  • リンク集

2最初に1回だけ：ホーム画面に追加する

ここは必ずやってください。追加しないと、電波の届かない関与先で使えなくなることがあります（理由は3.）。

iPhone・iPad の場合

  1. Safari で上のURLを開く
  2. 画面下の共有ボタン（□から↑が出ているマーク）を押す
  3. メニューを下にたどって 「ホーム画面に追加」 を押す
  4. 名前が 「税額ポケット」 になっていることを確認して「追加」

Edge や Chrome の共有メニューからも追加できます（iOS 16.4 以降）。どれで追加しても構いません。

Android の場合

  1. Chrome で上のURLを開く
  2. 右上の ︙（縦3つの点）を押す
  3. 「ホーム画面に追加」（または「アプリをインストール」）を押す
  4. 「追加」を押す
追加したら、続けてこれをやってください

ホーム画面のアプリは、ブラウザとは別々にデータを持ちます（理由は3.）。ブラウザで見ておいても、アイコンのアプリ側に入っているとは限りません。

追加したら必ずアイコンから開き直して、メニューを上から順に1回ずつ表示してください。30秒で終わります。これをやった端末は、電波のない場所でも確実に動きます。

3なぜホーム画面に追加が必要か

理由は2つあります。どちらも Apple の公式資料で確認しています。

① ホーム画面のアプリは、ブラウザとデータが別々です。

Apple の資料に「ホーム画面のWebアプリは、ブラウザとは別のクッキーとストレージを持つ」とあります。そのため、ブラウザで開いて見ておいても、アイコンのアプリ側に入っているとは限りません。追加したあとに、アイコンから開いて各メニューを1回ずつ表示してください。

② ブラウザのままだと、しばらく使わない間に保存データが消えます。

Safari は、7日間使わなかったサイトの保存データを自動的に削除します。

つまりホーム画面への追加は「アイコンから開けて便利」という話ではなく、電波が届かない場所でも動かすための条件です。ブックマークやお気に入りに入れただけでは、この効果はありません。

4使い方

  1. アイコンから開く
  2. メニューから計算したいものを選ぶ
  3. 金額などを入れると、その場で結果が出る（「計算」ボタンを押す必要はありません）
  4. 別の計算をするときは、左上の 「メニュー」 から戻る

開きっぱなしにしていたときは、いったんメニューへ戻って入り直してください。税率表は、メニューから計算画面に入るたびに最新を取りに行く作りです。朝に開いたまま夕方に使うと、その日の差し替えが反映されていないことがあります。

5電波がないところで使う

アイコンから開いて各メニューを1回ずつ表示してあれば、電波がなくても計算できます。

はじめて使う端末は、事務所を出る前に、ホーム画面のアイコンから開いて各メニューを1回ずつ表示してください（2. の最後と同じことです。ブラウザで見ただけでは足りません）。

6税制改正が反映されたときの知らせ方

税率や金額が変わったときは、チャットワークの「税額ポケット」グループに投稿します。

自分の端末に反映されているかは、メニューの「更新の確認」で確かめられます。お知らせに書いてある数値表の名前と日付を、この画面の同じ行と見比べてください。同じなら反映済みです。

お知らせに書いてある日付は、投稿した日ではありません。数値表そのものに書かれている日付（アプリの画面に出ているのと同じもの）です。「8月10日に更新しました」ではなく「延滞税・利子税の割合 → 2026年8月10日」の形で書きます。

日付が古いままのとき

  1. 通信できる場所で「更新の確認」をもう一度開く
  2. それでも変わらないときは、アプリをいったん閉じて開き直す
  3. なお直らないときはチャットワークのグループに書いてください（端末側の不具合の可能性があります）
メニューに「更新の確認」が見当たらないとき

その端末が古いままです。アプリをいったん閉じて、通信できる場所で開き直してください。

計算のしかたが変わったとき（アプリの版）

税率表の差し替えではなく、計算そのものを直したときは、お知らせに「アプリの版：v11」のように書きます。このときはアプリをいったん閉じて開き直してから、「更新の確認」の一番上に出ている版を見比べてください。

数値表の日付だけが新しくて版が古い場合、古い計算のしかたで新しい数値を使っている状態です。

7使うときの注意

  • 計算結果は概算です。申告その他の税務判断の根拠には使えません
  • 入力した金額は端末の外に出ません（どこのサーバーにも送っていません）。ただし関与先では画面の見え方に配慮してください
  • 相続税の概算・ふるさと納税は、まだ入っていません
  • リンク集の各リンクには適用年度が書いてあります。年度を必ず確かめてから開いてください

8要望・不具合

チャットワークの「税額ポケット」グループへ。特に次の2つを聞かせてください。

  1. 関与先で実際に開いたか
  2. 次にどのメニューが欲しいか

本ツールの計算結果は概算であり、申告その他の税務判断の根拠として用いることはできません。実際の税額は個別の事情により異なります。
