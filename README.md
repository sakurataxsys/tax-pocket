# 税額ポケット（tax-pocket）

客先で使う税額計算ツール。スマートフォン（iPhone / Android）のブラウザで開き、ホーム画面に追加してアプリのように使う。

> **免責**：本ツールの計算結果は概算であり、申告その他の税務判断の根拠として用いることはできません。実際の税額は個別の事情により異なります。

---

## 使い方（職員向け）

*(URL とホーム画面への追加手順は、第1ステップの実装後に実機で確認してから記載する)*

1. スマートフォンのブラウザで下記URLを開く
   - `https://sakurataxsys.github.io/tax-pocket/`
2. ホーム画面に追加する（手順はOS・ブラウザで異なるため、別紙の手順書を参照）
3. 以後はホーム画面のアイコンから開く

**電波が届かない場所でも動きます**（一度開いておけば、その時点の内容で計算できます）。

## 収録メニュー

### 計算

| メニュー | 内容 | 状態 |
|---|---|---|
| 退職金 | 退職所得の計算 | 未着手 |
| 減価償却費 | 定額法・定率法 | 未着手 |
| 印紙税 | 契約書等の記載金額から | 未着手 |
| 登録免許税 | 登記の種類・課税標準から | 未着手 |
| 延滞税・利子税 | 納付遅延日数から | 未着手 |
| 相続税の概算 | 財産額・法定相続人から | 未着手 |
| ふるさと納税シミュレーター | 控除限度額の目安 | 未着手 |

### 参照

| 画面 | 内容 | 状態 |
|---|---|---|
| 法人税の実効税率・均等割 早見表 | 所得規模別の目安と均等割 | 未着手 |
| 税額表・社会保険料率等リンク集 | 国税庁・協会けんぽ等への導線 | 未着手 |
