# 税額ポケット（tax-pocket）

関与先で使う税額計算ツール。スマートフォン（iPhone / Android）のブラウザで開き、ホーム画面に追加してアプリのように使う。

> **免責**：本ツールの計算結果は概算であり、申告その他の税務判断の根拠として用いることはできません。実際の税額は個別の事情により異なります。

---

## 使い方（職員向け）

配布用の手順書 → **[docs/配布手順書.md](docs/配布手順書.md)**（実機確認が済むまでは配布しない）

1. スマートフォンのブラウザで下記URLを開く
   - `https://sakurataxsys.github.io/tax-pocket/`
2. ホーム画面に追加する（手順はOS・ブラウザで異なるため、上の手順書を参照）
3. 以後はホーム画面のアイコンから開く

**電波が届かない場所でも動きます**（一度開いておけば、その時点の内容で計算できます）。
改正が反映されたかは、メニューの **「更新の確認」** で見られます（判断ログ D-25）。

### 構成

```
tax-pocket/
├── CLAUDE.md              設計原則・スコープ・禁止事項
├── index.html             アプリシェル（画面はここ1枚。#/ でメニューを切り替える）
├── sw.js                  service worker（オフライン動作・改正の反映）
├── manifest.webmanifest   ホーム画面に追加したときの名前・アイコン
├── docs/                  仕様・判断ログ・改正対応手順
├── data/                  ★税率表・リンク集（毎年ここを差し替える）
├── src/                   画面と計算ロジック
├── styles/                画面の型
├── icons/                 ホーム画面のアイコン（原稿は tools/icon-source.html）
├── tests/                 税務ロジックのテスト
└── tools/                 開発用（ローカルサーバ・アイコン原稿・償却率表の生成）
```

### 動かす

```
npm test              テスト（依存パッケージなし。Node の標準機能だけで動く）
node tools/serve.mjs  http://localhost:8080/ で配信（service worker は file:// では動かない）

node tools/fetch_shokyakuritsu.mjs   減価償却の償却率表を耐用年数省令の別表から作り直す
node tools/build_tejunsho_pdf.mjs    配布手順書の PDF を HTML から起こす（出力は ClaudeDocument/output）
```

**`src/` のロジックを変えたら版を上げること。** 上げる場所は2つで、同じ値にする。

- `sw.js` の `CACHE_VERSION`（キャッシュの入れ替え用）
- `src/version.js` の `APP_VERSION`（画面に出す用。ずれると `npm test` が落ちる）

`data/*.json` を差し替えるだけの改正では上げる必要はない（判断ログ D-16）。

**このリポジトリは公開されています。** 顧問先名・個人名・実際の金額・鍵・社内URLを含めないでください（詳細は [CLAUDE.md](CLAUDE.md) 冒頭）。
